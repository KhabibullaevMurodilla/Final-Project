Heliocentric distance

The location model — a single-layer LSTM — reads the last 120 hours of position (distance, latitude, longitude) and predicts the next hour, rolled forward autoregressively for the full forecast window.

HGI_R — distance from the Sun (AU) observed forecast

Interstellar particle flux

The parameter model — a stacked 3-layer LSTM — forecasts all 28 non-position channels at once: magnetic field, solar wind, and 18 LECP/CRS proton-flux energy bands. Shown below: the lowest-energy flux channel, the noisiest and most cosmic-ray-sensitive of the eighteen.

Flux_1 — proton flux, <2 MeV channel observed forecast

Is the forecast actually any good?

The honest check: hold out the last 72 hours of already-observed data, forecast that same window using only the data before it, then compare. This is what the forecast chart above can't show on its own — how far the model's autoregressive rollout drifts from reality as the horizon grows.

HGI_R — 72h held-out backtest actual model's forecast
Error vs. forecast horizon HGI_R Flux_1

Error shown as % of each variable's observed range — comparable across very different units. Climbing lines mean exactly what they look like: trust the first day or two of the forecast far more than the last.

The two models

Both are real, trained artifacts from the original project — loaded here, not reconstructed. Architecture and loss figures below are read directly off their training run.

location_model.h5

param_model.h5

LSTM(128, relu) → LSTM(64, relu) → LSTM(32, relu) → Dense(28) input: (120, 31) · output: (28)
Train MSE (scaled): 1.29 × 10⁻⁴

Pipeline

Ingestion → cleaning → autoregressive rollout → export, matching the original notebook's logic exactly, now as reusable modules instead of one long cell sequence.

01

Ingest

Parse NASA's whitespace-delimited .asc files into the 34-column schema.

02

Clean

Null out the 9-fill convention (999.999, 9.999e+05), index by hour, drop gaps.

03

Scale

Min-max normalize all 31 columns; build 120-hour input sequences.

04

Forecast

Roll both LSTMs forward hour by hour, feeding each prediction back in.

05

Export

Inverse-transform to physical units, write forecast.json for this page.
